# pdfkit-table — example-server

Express + TypeScript server that demonstrates how to use **pdfkit-table** to generate PDF files on the server side.

---

## Requirements

- Node.js >= 18
- npm >= 9

---

## Install

```bash
cd example-server
npm install
```

---

## Run

### Development (no build step)

```bash
npm run dev
```

### Production

```bash
npm run build
npm start
```

The server starts on **http://localhost:3030**

---

## Endpoints

| Method | URL | Description |
|--------|-----|-------------|
| GET | `/pdf/simple` | Array-based table — simple rows with padding |
| GET | `/pdf/full` | Object-based table — product list with column renderers, alignment and header colors |

Open either URL in the browser to view the PDF inline.  
A copy is also saved to disk inside `example-server/` as `simple-table.pdf` / `full-table.pdf`.

## How it works

```ts
import { createPdfDocumentWithTables } from "pdfkit-table";

const PDFDocument = createPdfDocumentWithTables(require("pdfkit"));
const doc = new PDFDocument({ margin: 30, size: "A4" });

// stream to HTTP response
res.setHeader("Content-Type", "application/pdf");
doc.pipe(res);

// add a table
await doc.table(
  {
    headers: ["Country", "Conversion rate", "Trend"],
    rows: [
      ["Switzerland", "12%", "+1.12%"],
      ["France",      "67%", "-0.98%"],
    ],
  },
  { width: 400, padding: [8, 10, 8, 10] },
);

doc.end();
```
